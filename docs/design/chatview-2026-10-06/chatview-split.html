Today one 5,645-line file reads twenty kinds of messages and guesses which ones belong to which reply. The split gives every reply one folder with numbered pages, and every kind of page gets its own small viewer.

How the file splits

Think of today's chat view as one clerk at a front desk. Twenty couriers drop envelopes, and the clerk matches them to replies by reading the turn number on each one. When a match fails, a card goes to the "orphan" pile or a reply goes to the wrong thread.

After the split, the backend sends one numbered folder per turn. One store files the pages. Small viewers only draw what the store holds, and they do not guess.
