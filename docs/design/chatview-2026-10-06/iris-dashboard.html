The dashboard joins the spine

Your chat now has a Xur, a spine, an edge light and one ◉ menu. Until now the dashboard only borrowed the ink. In this revision it is built from the same parts, so the two wings read as one instrument.

  • One ◉ menuThe same button and the same menu in both wings. The first item swaps: the chat menu offers the dashboard, the dashboard menu offers the chat.
  • The rail is a spineThe six settings places and the tools sit on one particle line. The Xur rides it to where you are.
  • Settings read before you open themEach settings box becomes a row that shows its current values in one line. Open it and the line lights.
  • Calm controlsDropdowns, switches and sliders use the composer's ink, hairlines and mono numbers. A changed value gets the amber dot that IRIS uses for work in progress.
  • Apply where you typeThe Apply bar sits where the chat's message box sits, and it names what you changed.
  • The hub keeps its toolsTerminal, tasks and archive stay. Things you drag from the chat land in a Views lane beside them.

Two signs, one meaning each

In a project, # and @ also appear in code: a heading, an issue number, a decorator, a package scope. So each sign has one job, and it opens a list only when the message needs it.

What stays and what changes

  • STAYSEvery setting, its saved value and its handler. Apply still commits all changes at once.
  • STAYSSpotlight: the spotlit wing is 680 px; the other is 360 px at opacity 0.3 with saturate(0.6) blur(2px), and it takes no clicks. The aperture keeps its place on the top edge.
  • STAYSThe Workspace hub keeps its terminal, task lanes, archive and file tabs. Dropped items never become project files and never hide a lane.
  • STAYSBrowser, Models, Marketplace and the Inference console keep their own content. They get the new header and rail only.
  • CHANGESHeader: the row of four icon buttons (open chat, detach, launcher, alerts) moves into the ◉ menu. It is the same menu component as the chat.
  • CHANGESThe rail: icon circles become places on a spine with names; the Xur button folds it to orbs only.
  • CHANGESSettings boxes: a row with a one-line summary replaces the bordered box with a chevron. Open rows light their hairline; changed values get an amber dot and the row counts them.
  • CHANGESA "find a setting" field at the top searches every place, the same way the thread orbit finds threads.
  • TO DECIDEFiles under # (this page) or under a sign of their own. I recommend # with two groups, because one sign for "point at something" is easier to remember.
