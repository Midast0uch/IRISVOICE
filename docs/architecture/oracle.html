Three rules

What keeps it honest

1. The Oracle never writes the world. Its only output is a score table. One ledger writer (AgentToolBridge._record_tool_event) puts the decision on the SAME row as the outcome.

2. The Brain never picks cheap. Routine choices cost no reasoning call; the Brain sees only below-threshold picks, DELEGATE and broken arguments.

3. Nobody guesses the pass mark. The threshold is keyed by the backend identity gliner25-decide-onnx-int8 (0.40). An unknown backend or a changed menu width enforces nothing.

The Oracle's own guesses are never evidence. Evidence comes from outside: a test, a completion, the user, recurrence, corroboration. Click a box for details.
