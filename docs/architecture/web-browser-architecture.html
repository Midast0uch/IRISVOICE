How to read it

A building with nine floors

Each floor is who acts. Top: you and the interface. Then the gate (the web toggle — the front door key), the deciders (the editor who plans the story), the tools (three ways to get facts: read the headlines = search, read the articles = crawl, walk into the building and ask at the desk = browser), the runtime that drives Chromium and the crawler, vision (the eyes when a sign has no text), memory (the notebook) and the events that come back to your screen.
