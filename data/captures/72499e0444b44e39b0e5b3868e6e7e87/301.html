    Get Started with GeForce NOW for Linux

    1. Download the .bin file below.
    2. Make the file executable. Right-click the file > Properties and enable "Executable as Program" or run this command in your terminal: chmod +x GeForceNOWSetup.bin
    3. Run the installer to complete setup.

    Prefer to install as a Flatpak from the command line?

    Add the official NVIDIA GeForce NOW repository

    flatpak remote-add --user --if-not-exists GeForceNOW https://international.download.nvidia.com/GFNLinux/flatpak/geforcenow.flatpakrepo

    Install GeForce NOW

    flatpak install --user GeForceNOW com.nvidia.geforcenow

    Launch GeForce NOW

    flatpak run com.nvidia.geforcenow
