**Evidence rule — DEMONSTRATE, never assert.** For every exit criterion above, the implementing agent
SHALL paste the actual output that proves it (the `[DER] budget=… from window=…` line, the measured
call count, the row count from the configured store, the failing-then-passing test name) into the wave
report. "Done" / "verified" / "should now work" without the output does not close a criterion.
This project's recurring defect is code that is built, tested, and never wired — this session alone
found `der_steps` (declared, never assigned), `captureJobId` (declared, never written), `job_id`

assertion instead of an observation. A green unit test is NOT evidence that a path runs in production.
