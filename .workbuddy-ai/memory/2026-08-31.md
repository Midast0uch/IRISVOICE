### Build gotcha (will recur) — TWO guards, both must be cleared
`npm run build:static` FAILS under the WorkBuddy Bash tool unless both env vars
are set. Working command:
```
CODEBUDDY_SAFE_DELETE_ENABLED=0 CODEBUDDY_SAFE_DELETE_BULK_THRESHOLD=100000 npm run build:static
```
1. `SAFE_DELETE_BULK_CONFIRM_REQUIRED {count:50, threshold:50, scope:"turn"}`
   — Next deletes hundreds of regenerable build-cache files; the guard counts
   CUMULATIVELY PER TURN. Raising the threshold fixes this one.
2. `genie-trash/win32-x64.exe ETIMEDOUT` — the trash-by-binary path times out
   during "Finalizing page optimization". Needs `ENABLED=0`.

Failure mode to watch: the build dies AFTER "Generating static pages (8/8)"
during "Finalizing page optimization", leaving `dist/` PARTIALLY WRITTEN and
BROKEN (53 files, no index.html) — worse than the stale version it replaced.
